YouTube Tweaks + Ubuntu Light

Набор userscript-ов: кастомизация YouTube и шрифт Ubuntu Light для всех сайтов.

📥 Установка

Установить YouTube Tweaks
Установить Ubuntu Light Font

📦 Что делает каждый скрипт

  • YouTube Tweaks — скрытие элементов, авто-качество (FHD/2K/4K), скорость колесом, перевод комментариев, компактный режим.
  • Ubuntu Light Font — применяет шрифт Ubuntu Light ко всему контенту на всех сайтах.

⌨️ Горячие клавиши (YouTube Tweaks)

  • F2 — открыть панель настроек
  • Ctrl + ↑ / ↓ — изменить скорость видео
  • Ctrl + 0 — сбросить скорость на 1×
