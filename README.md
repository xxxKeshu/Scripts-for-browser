# YouTube Tweaks

Набор userscript-ов: кастомизация YouTube + шрифт Ubuntu Light для всех сайтов.

## 📦 Скрипты

| Файл | Описание |
|---|---|
| [`youtube-tweaks.user.js`](./youtube-tweaks.user.js) | Кастомизация YouTube: скрытие элементов, авто-качество, скорость, перевод комментариев |
| [`ubuntu-light-font.user.js`](./ubuntu-light-font.user.js) | Применяет шрифт Ubuntu Light ко всему контенту на всех сайтах |

## 🚀 Установка

1. Установите [Violentmonkey](https://violentmonkey.github.io/) (рекомендуется) или Tampermonkey.
2. Откройте нужный `.user.js` файл в этом репозитории.
3. Нажмите **Raw** — менеджер скриптов предложит установку.
4. Готово.

**Прямые ссылки для установки:**

- [📥 Установить YouTube Tweaks](https://raw.githubusercontent.com/xxxKeshu/Scripts-for-browser/main/youtube-tweaks.user.js)
- [📥 Установить Ubuntu Light Font](https://raw.githubusercontent.com/xxxKeshu/Scripts-for-browser/main/ubuntu-light-font.user.js)

## ⌨️ Горячие клавиши (YouTube Tweaks)

- **F2** — открыть/закрыть панель настроек
- **Ctrl + ↑ / ↓** — изменить скорость видео
- **Ctrl + 0** — сбросить скорость на 1×
